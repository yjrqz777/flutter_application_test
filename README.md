# 多功能调试工具

面向硬件调试的 Flutter 工具：查看陀螺仪与姿态角，用经典蓝牙或 BLE（Bluetooth Low Energy，低功耗蓝牙）串口和板子收发数据。

## 功能

- 陀螺仪角速度实时显示，Mahony 互补滤波融合出姿态角（roll / pitch / yaw）
- 经典蓝牙（SPP，Serial Port Profile，串口协议）串口收发调试
- BLE 串口（GATT，Generic Attribute Profile，通用属性协议透传）收发调试
- 「服务与特征」页：列出连接设备的全部服务和特征，手动指定收发用哪两条
- 服务和特征显示 SIG（Special Interest Group，蓝牙技术联盟）标准名称，例如 `0x1800 Generic Access`
- 控制台：系统事件和收发日志集中查看，按来源筛选、记录等级可调，按天落盘
- 经典蓝牙和 BLE 合并在同一个「蓝牙调试」页，顶部用分段按钮切换模式
- 经典蓝牙列表里标出已配对设备
- 普通 / 自定义两种串口调试页，时间戳、字节计数、方向标签、HEX 视图、快捷指令栏可开关
- 亮色 / 暗色主题切换

## 页面

| 页面 | 说明 |
| --- | --- |
| 入口页 | test、蓝牙调试、关于三个圆形入口，页面从按钮圆心展开 |

| 关于 | 应用信息与功能列表 |

### 蓝牙调试页

- 顶部分段按钮在「经典蓝牙」和「BLE 蓝牙」之间切换，扫描、连接、断开的都是当前模式。
- 经典蓝牙模式一进页面就加载系统里已配对的设备，列表副标题显示「已配对 / 配对中 / 未配对」。
- 状态文字和扫描按钮同一行：文字在左，按钮在右。
- 正在扫描时切换模式会先停止扫描；已连接或正在连接时切换会提示先断开。
- BLE 连上后，控制台工具栏的「服务与特征」图标可以打开服务清单，把「写 / 收」指到真正的那两条特征。


## 运行

需要 Flutter SDK（Dart 3.12 及以上）。Android 手机和 Windows / Linux 桌面都能跑，蓝牙功能要求设备本身有对应硬件。

```bash
flutter pub get
```

```bash
flutter run
```

### 手机无线调试

1. 手机和电脑连同一个 Wi-Fi，打开「开发者选项 → 无线调试」。
2. 点「使用配对码配对设备」，记下屏幕上的 IP:端口 和六位配对码。
3. 电脑上配对，按提示输入配对码：

```bash
adb pair 192.168.1.5:37123
```

4. 回到无线调试页，用「IP 地址和端口」连接：

```bash
adb connect 192.168.1.5:41234
```

5. 直接跑到手机上：

```bash
flutter run -d 192.168.1.5:41234
```

## 更新记录

### 2026-11-24

- 新增「控制台」页：系统事件和收发日志集中显示，按来源（系统 / 发送 / 接收）筛选，记录等级可设为全部、警告以上或仅错误，选择存在 `settings.conf` 里。
- 日志按天写进 App 临时目录下的 `multifunction_debug_tool_logs`，保留 7 天，单文件 8MB 上限，启动时回读当天最近的记录。
- 日志内容补齐：状态变化、设备名与地址、扫描发现、服务与特征清单、MTU 与写包细节、异常调用栈。
- 新增「服务与特征」页：BLE 连上后列出全部服务和特征，可手动指定发送、接收用的特征。
- 服务和特征的 UUID 在界面和控制台日志里都显示 SIG 标准名称，名称表含 68 个标准服务、475 个标准特征，另补 4 个常见成员服务（`0xfe95` 小米 MiBeacon、`0xfe2c` Fast Pair、`0xfe59` Nordic DFU、`0xfeaa` Eddystone）。
- 16 位 UUID 统一显示成 `0x` 前缀，128 位完整 UUID 保持原样。
- 「收发记录」只保留收发数据和发送相关提示，连接、扫描、服务发现这类过程信息只进控制台。
- 串口工具栏改成一行布局：左边两行文字紧凑排列，右边的图标和开关垂直居中，上下留白统一。
- 发送框提示文案缩短为一行。
